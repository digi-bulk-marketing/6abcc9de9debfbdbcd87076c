# Veer WhatsApp Message Sender

Veer WhatsApp Message Sender by Veerinfotech.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/6abcc9de9debfbdbcd87076c/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Veer WhatsApp Message Sender** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/6abcc9de9debfbdbcd87076c/releases/latest) and reinstall.
